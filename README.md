# 🎯 Kumpulan Soal & Writeup CTF (Capture The Flag)

Repository ini berisi kumpulan file soal, tantangan, dan catatan penyelesaian (*writeup*) kompetisi CTF yang telah saya pelajari. Dibuat sebagai dokumentasi pribadi untuk keperluan kuliah, latihan mandiri, dan persiapan kompetisi di bidang *Cyber Security*.

---

## 📂 Daftar Isi Kompetisi
Berikut adalah daftar tantangan CTF yang ada di dalam repository ini:
* **BootcampCTF 2025** - Tantangan tingkat dasar untuk pemula.
* **Comfest 13** - Kumpulan soal CTF tingkat nasional.
* **CTF-Hology 4.0** - Fokus pada eksploitasi sistem dan jaringan.
* **Google CTF** - Tantangan tingkat internasional (*advanced*).
* **IFEST 2020** - Arsip soal kompetisi akademis kampus.
* **Slashroot 8** - Fokus pada keamanan web dan kriptografi.

---

## 🛠️ Kategori Tantangan & Tools yang Digunakan
Dalam menyelesaikan soal-soal ini, saya mempelajari beberapa kategori utama:

1. **Web Exploitation**
   * *Tools:* Burp Suite, Dirsearch, Nmap, SQLMap.
2. **Cryptography & Forensics**
   * *Tools:* CyberChef, Wireshark, Exiftool, Steghide.
3. **Reverse Engineering & Pwn**
   * *Tools:* Ghidra, GDB, Python (Pwntools).
